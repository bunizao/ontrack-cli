# ontrack-cli 0.1.3

This is the final Python release before the TypeScript cutover.

- Authentication now reuses an existing `okta` CLI session through its stable JSON subprocess interface.
- `ONTRACK_HTTP_RECORD` can capture allowlisted, sanitized user-scoped API contracts for migration testing.
- Authentication headers, cookies, hostnames, usernames, and tokens are never written to recordings.

The next release moves installation from PyPI to the npm package `ontrack` while retaining the `ontrack` executable name. Existing Python releases remain available, but receive no features after this migration release.
